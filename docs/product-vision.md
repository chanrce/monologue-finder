# Product Vision

## Project Name

Dramaturg

## Project Scope

Dramaturg is a web application that enables actors to search and discover audition monologues using search filters and AI recommendations. The project involves backend API development, database design, AI integration, and cloud deployment.

## Elevator Pitch

An AI-powered platform that helps actors discover the perfect monologue for their audition.

## Problem

Actors are often faced with limited monologue content, preventing from putting their best foot forward as casting directors are tired of hearing the same material. Many actors also struggle to find monologues that fit specific criteria, whether it's a certain theme, tone, character type, or actor type.

## Target Users

High school actors
College actors
Professional actors
Community theater actors
Acting teachers

## Goals

Find audition monologues efficiently
Discover lesser-known pieces
Save favorite monologues
Receive personalized recommendations
Organize audition materials

## Non-Goals

Social media
Messaging
Casting website
Mobile App

## MVP

Search monologues
Filter results
View monologue details

## Success Metrics

User can find a relevant monologue using search and filters

Search returns accurate results

API responds in under 500 ms for search es

User can successfully save and retrieve favorite monologues

AI recommendations match the user's requested criteria
